# AllTogether · live page

The hosted page for **AllTogether** on NEAR testnet: **https://aarash-mohsin.github.io/alltogether-live/**

- **Plans:** the public board of every plan, with an open plan you can pledge to from your own NEAR testnet wallet (claim 1,000 testUSD from the demo faucet first)
- **People:** each named account's record across plans: backed, completed, refunded
- **DAO:** which Sputnik DAO flows are used as is and what AllTogether adds, with every proposal and its vote
- **Verify:** 18 PASS/FAIL checks computed in your browser from public NEAR testnet RPC

Nothing is signed unless you connect a wallet, and the page holds no keys. This repository holds only the built static files. The source, contracts and tests are in
[aarash-mohsin/alltogether-near](https://github.com/aarash-mohsin/alltogether-near) (`site/`, built with `npm run build:site`).
